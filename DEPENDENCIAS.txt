═══════════════════════════════════════════════════════════════════════════════
                          DEPENDENCIAS DE PRODUCCIÓN
═══════════════════════════════════════════════════════════════════════════════

1. @redocly/openapi-cli (v1.0.0-beta.79)
   ├─ Descripción: Herramienta CLI para trabajar con especificaciones OpenAPI
   ├─ Uso: Bundling, linting y validación de archivos OpenAPI YAML
   ├─ Comandos: openapi bundle, openapi lint
   └─ Documentación: https://redocly.com/docs/cli/

2. redoc-cli (v0.13.2)
   ├─ Descripción: Generador de documentación API a partir de OpenAPI
   ├─ Uso: Crear documentación HTML estática interactiva
   ├─ Comandos: redoc-cli serve, redoc-cli bundle
   └─ Documentación: https://github.com/Redocly/redoc

═══════════════════════════════════════════════════════════════════════════════
                         DEPENDENCIAS DE DESARROLLO
═══════════════════════════════════════════════════════════════════════════════

1. jest (v29.7.0)
   ├─ Descripción: Framework de testing para JavaScript
   ├─ Uso: Ejecutar pruebas unitarias y de integración
   ├─ Comandos: jest, npm test
   ├─ Características: Coverage, mocking, assertions
   └─ Documentación: https://jestjs.io/

2. @apidevtools/swagger-parser (v10.1.0)
   ├─ Descripción: Parser y validador de esquemas OpenAPI/Swagger
   ├─ Uso: Validar sintaxis y referencias en archivos OpenAPI
   ├─ Funciones: validate(), parse(), dereference()
   └─ Documentación: https://apitools.dev/swagger-parser/

3. axios (v1.13.2)
   ├─ Descripción: Cliente HTTP basado en promesas
   ├─ Uso: Hacer peticiones a la API real de Kitsu para testing
   ├─ Características: Interceptores, transformadores, timeout
   └─ Documentación: https://axios-http.com/

4. yaml (v2.3.4)
   ├─ Descripción: Parser de archivos YAML para Node.js
   ├─ Uso: Leer y procesar archivos YAML de configuración
   └─ Documentación: https://eemeli.org/yaml/

═══════════════════════════════════════════════════════════════════════════════
                        DEPENDENCIAS TRANSITIVAS (PRINCIPALES)
═══════════════════════════════════════════════════════════════════════════════

Estas se instalan automáticamente con las dependencias principales:

- chalk: Colorización de output en terminal
- js-yaml: Parser YAML adicional
- glob: Pattern matching de archivos
- handlebars: Motor de plantillas
- marked: Parser de Markdown
- react: Librería UI para Redoc
- react-dom: Renderizado de React
- styled-components: CSS-in-JS para Redoc
- yargs: Parser de argumentos CLI

═══════════════════════════════════════════════════════════════════════════════
                           COMANDOS DE INSTALACIÓN
═══════════════════════════════════════════════════════════════════════════════

# Instalación inicial completa
npm install

# O con yarn
yarn install

# Instalación solo de producción (sin testing)
npm install --production

# Instalación de dependencias individuales (si es necesario)
npm install --save @redocly/openapi-cli@1.0.0-beta.79
npm install --save redoc-cli@0.13.2
npm install --save-dev jest@29.7.0
npm install --save-dev @apidevtools/swagger-parser@10.1.0
npm install --save-dev axios@1.13.2
npm install --save-dev yaml@2.3.4

═══════════════════════════════════════════════════════════════════════════════
                              SCRIPTS DISPONIBLES
═══════════════════════════════════════════════════════════════════════════════

npm run build        → Bundlea los archivos YAML en un solo kitsu.yml
npm run lint         → Valida el esquema OpenAPI
npm run serve        → Inicia servidor de desarrollo de documentación
npm run serve:bundle → Genera HTML estático de la documentación
npm start            → Build + Lint + Serve (desarrollo completo)
npm test             → Ejecuta todas las pruebas con Jest
